# SEO Strategy — Sito Prezzo Fisso

## Obiettivo

Acquisire utenti italiani con intento commerciale verso la realizzazione di siti web, senza dipendere esclusivamente da keyword altamente competitive come:

- realizzazione siti web Milano;
- web agency Como;
- web designer Ravenna.

## Strategia principale

### 1. Verticali per professione

Cluster iniziale:
- sito web per idraulico;
- sito web per imbianchino;
- sito web per elettricista;
- sito web per impresa edile;
- sito web per serramentista;
- sito web per falegname;
- sito web per giardiniere;
- sito web per geometra;
- sito web per termoidraulico;
- sito web per impresa pulizie;
- sito web per fabbro;
- sito web per piastrellista;
- sito web per lattoniere;
- sito web per fiorista;
- sito web per commercialista.

Ogni pagina deve essere veramente specifica per quella professione.

Differenziare:
- esigenze del mestiere;
- servizi da mostrare;
- struttura ideale del sito;
- CTA;
- funzionalità;
- demo;
- FAQ;
- errori comuni;
- esempi di contenuto.

Non creare semplici sostituzioni di keyword.

### 2. Prezzo e modello commerciale

Target:
- quanto costa un sito web;
- costo sito web;
- sito web 400 euro;
- sito web prezzo fisso;
- sito web economico professionale;
- sito vetrina prezzi;
- sito web senza abbonamento;
- costo sito artigiano.

Queste pagine devono avere forte intento commerciale e trasparenza.

### 3. Problemi e decisioni

Esempi:
- sito web o pagina Facebook;
- serve davvero un sito a un artigiano;
- cosa deve avere il sito di un idraulico;
- sito statico o WordPress;
- quanto costa mantenere un sito.

### 4. Demo

Le demo devono essere veri asset di conversione e differenziazione.

Non creare aziende reali fittizie.
Usare nomi chiaramente dimostrativi.

### 5. Local SEO

Non generare città in massa.

Usare pagine locali soltanto se:
- Search Console mostra domanda;
- l'intento è commerciale;
- esiste contenuto utile realmente distinto;
- la pagina non è una doorway;
- non viene dichiarata una presenza fisica inesistente.

Non creare fake sedi o Google Business Profile.

### 6. Search Console driven SEO

Espandere il sito soprattutto quando i dati mostrano:
- query con impression;
- posizione 8-30;
- CTR basso;
- cluster di query non soddisfatte;
- nuove long-tail pertinenti.

## Internal linking

Collegare:
- verticali → prezzo;
- verticali → demo;
- verticali → richiedi sito;
- articoli prezzo → verticali;
- articoli decisionali → pagine commerciali;
- demo → pagina professione;
- FAQ → pagine pertinenti.

## Backlink

Non usare sistemi automatici di link building.

Preferire asset linkabili:
- demo;
- dati originali;
- guide concrete;
- case study;
- tool utili;
- repository open source se sensato.

## Principio guida

Meglio 30 pagine utili che 3.000 pagine programmatiche senza valore.

Per la progettazione e la verifica delle future pagine verticali, seguire il [Vertical Page Playbook](VERTICAL_PAGE_PLAYBOOK.md).
