# Sito Prezzo Fisso

## Dominio
https://sitoprezzofisso.it

## Obiettivo

Costruire un sito italiano che acquisisca clienti interessati alla realizzazione di un sito web semplice, professionale e a prezzo fisso.

L'offerta principale è un sito web standardizzato a **399 €**, pensato soprattutto per:
- artigiani;
- microimprese;
- professionisti;
- piccole attività locali.

Il servizio deve essere vendibile e gestibile quasi interamente in modo asincrono, soprattutto via email.

## Modello commerciale

### Offerta base — 399 €

Il cliente acquista un sito semplice e professionale con scope molto chiaro.

Indicativamente include:
- sito vetrina;
- massimo 3 pagine oppure struttura one-page equivalente;
- design professionale basato su template adattato;
- responsive;
- modulo contatti;
- eventuale pulsante WhatsApp;
- SEO tecnica di base;
- title e meta description;
- sitemap;
- predisposizione Search Console;
- collegamento dominio;
- massimo 3 cicli di revisione;
- comunicazione ordinaria via email.

Le revisioni devono essere consolidate: ogni ciclo di revisione deve arrivare come una singola richiesta complessiva.

### Fuori scope

Non fanno parte dell'offerta base:
- ecommerce;
- gestionali;
- aree riservate;
- prenotazioni complesse;
- sviluppo custom significativo;
- branding completo;
- copywriting specialistico;
- fotografia;
- integrazioni complesse;
- revisioni illimitate.

### Progetto avanzato

Se il cliente ha esigenze superiori all'offerta base, deve poter richiedere fino a **2 preventivi** da professionisti o agenzie partner.

Il sito raccoglie la richiesta e, previo consenso esplicito dell'utente, potrà inoltrare i dati necessari a massimo due partner compatibili.

Non inventare partner, recensioni, clienti o collaborazioni.

## Posizionamento

Il servizio non deve sembrare cheap.

Il messaggio è:

> Processo standardizzato, prezzo chiaro, niente riunioni infinite, niente preventivi incomprensibili.

Non usare linguaggio da agenzia generica come:
- soluzioni a 360 gradi;
- partner digitale;
- innovazione su misura;
- esperienze digitali uniche.

## Principi

- prezzo trasparente;
- processo semplice;
- comunicazione prevalentemente via email;
- vendita asincrona;
- design professionale;
- sito velocissimo;
- SEO utile e non spam;
- crescita guidata dai dati reali di Search Console;
- nessuna promessa di posizionamento garantito;
- nessuna sede locale finta;
- nessuna recensione inventata.

## Strategia di crescita

Fase iniziale:
1. sito commerciale solido;
2. alcune pagine verticali per professione;
3. demo reali e curate;
4. contenuti commerciali su prezzo e scelta del sito;
5. raccolta dati Search Console.

Solo dopo:
- nuove professioni;
- eventuali pagine locali;
- nuove long-tail;
- pagine professione × città soltanto se i dati dimostrano un intento reale e se possono essere differenziate in modo utile.

## Tecnologia

Preferenza:
- Astro;
- output statico;
- GitHub Pages;
- GitHub Actions;
- dominio custom sitoprezzofisso.it;
- JavaScript client-side minimo;
- componenti riutilizzabili;
- dati separati dalla presentazione;
- nessun secret nel repository.

## Obiettivo operativo

Codex deve poter gestire quasi tutto:
- sviluppo;
- modifiche;
- contenuti;
- build;
- test;
- commit;
- push;
- manutenzione;
- analisi SEO periodica.

Il proprietario deve intervenire soprattutto per:
- controllo qualità;
- decisioni commerciali;
- gestione clienti;
- approvazione di modifiche importanti.
